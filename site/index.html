cdpx
Benchmarks MCP Setup GitHub
Standalone Rust Binary // AMD64 // Zero Node.js

Driverless, Token-Compressed Browser Engine for AI Agents.

Speaks raw Chrome DevTools Protocol over WebSockets. Compresses dynamic pages into <800 token interactive projections with zero Playwright driver leaks.

bash - cdpx

# 1. Open any page and output dense, interactive semantic handles

$ cdpx open "https://news.ycombinator.com"

[Page: Hacker News] (url: https://news.ycombinator.com)

@e1: link "Hacker News" (x: 135, y: 20)

@e2: link "new" (x: 194, y: 20)

@e3: link "comments" (x: 288, y: 20)

@e4: link "login" (x: 676, y: 20)


# 2. Fire trusted, two-phase CDP clicks with automatic hydration settling

$ cdpx click @e4


# 3. Expose as a zero-overhead stdio MCP server for Claude Code or Antigravity

$ cdpx --mcp

01 // Zero Node.js Tax

Spawning Playwright from Python or Go launches a 150MB+ Node.js subprocess. cdpx is compiled pure Rust on Tokio, idling under 22MB RSS.

02 // SASP Token Projection

Culls generic div-soup and offscreen footer noise. Emits visible, hit-tested interactive elements, reducing per-step context from 20k to <800 tokens.

03 // Hydration Dead-Click Fix

Monitors DOM mutation observers and React fiber queues before dispatching trusted pointerdown and pointerup sequences. Never clicks dead SSR buttons.
